# Tag Join: drop the trailing comma after the last tag

Behavior change per user decision: keep `", "` **between** tags, never append it **after the last** one. `red, blue` instead of `red, blue, `. No option widget — unconditional, YAGNI (chaining stays safe anyway: every Tag Join input strips leading/trailing commas per tag, and a Routing Switch branch is stripped too).

Bonus: the trailing comma was itself a CLIP content token — removing it frees one token per prompt in the token report / encoder window.
